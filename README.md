# NEXUS Mobile

Native SwiftUI companion app for the local NEXUS stack.

Open the `NexusMobile` folder in Xcode on a Mac or cloud macOS runner. Set the deployment target to iOS 17+, replace the default Tailscale hostname if needed, then sign with an Apple development team.

The PC wake action needs a configured Wake-on-LAN relay endpoint on the Raspberry Pi before it can be enabled.
